# SimpleMaps server.

This is a Rust implementation of Caraxi's [SimpleMaps' plugin's server implementation](https://github.com/Caraxi/SimpleMapTracker/tree/master/server).
I wrote it in Rust because I both wanted to learn more Rust, but I also wanted to fuck around with Websockets more.

I seen that [Caraxi's server](https://maps.caraxi.dev) was not responding correctly, so I wanted to make my own ahead of a maps run!
